Turn on the AI box in the Moon Desk

About 15 minutes, one time. You will make two free accounts, copy and paste once, and you are done. Nothing here needs a zip file or any coding.

1Get your AI key

Go to console.anthropic.com and sign in.

  1. Open Billing (or Plans & Billing) and add $10 of credit. Each question costs only a few cents, so this lasts a long time.
  2. Open Limits and set a monthly spend limit (for example $20) so the bill can never run away.
  3. Open API Keys, press Create Key, name it moon-desk, and copy the key. It starts with sk-ant-. Keep that window open until step 3 is done.

Never paste this key in the website file or send it to anyone. It goes only in step 3.

2Make the free helper

Go to cloudflare.com and make a free account (or sign in).

  1. On the left choose Workers & Pages, then Create, then Create Worker.
  2. Name it moon-ask and press Deploy.
  3. Press Edit code. Select everything in the editor (Ctrl+A) and delete it.
  4. Open the file moon-ask-worker.js I sent you (right-click it, Open with Notepad). Select all (Ctrl+A), copy (Ctrl+C), and paste it into the Cloudflare editor (Ctrl+V).
  5. Press Deploy at the top right.

3Give the helper your key (privately)

  1. In your moon-ask worker open Settings, then Variables and Secrets, then Add.
  2. Type: choose Secret. Name: ANTHROPIC_API_KEY. Value: paste your key from step 1. Press Deploy.
  3. Your access code is BBBDD by default. To change it, add a Text variable ACCESS_CODE with the new code. People enter the code once in the Moon Desk box and their browser remembers it.
  4. Optional safety limits (type Text): PER_IP_LIMIT = 20 questions per person per day, and DAILY_LIMIT = 300 questions per day in total. Those are already the defaults if you skip this.

The helper only answers requests that come from degendesk.blockwallstreet.biz. If your Degen Desk lives at another address, add a Text variable ALLOWED_ORIGIN with that exact address (for example https://degendesk.blockwallstreet.biz, no slash at the end).

4Copy the helper's address

On the worker's main page you will see a web address ending in .workers.dev, like https://moon-ask.something.workers.dev. Copy it.

5Connect the Moon Desk

  1. Upload the new moonbwsddp.html to your DegenDesk repo (Add file, Upload files, Commit changes). Wait a minute or two and press Ctrl+Shift+R on the Moon Desk page.
  2. Load an asset, scroll to Ask the Moon Desk, type a question, and press Ask. A box appears asking for the helper address. Paste it, press Save helper address, then press Ask again.

That saves it for your own browser. To make it work for everyone who visits, send me the address and I will build it into the page.

Good to know

  • Your key stays hidden inside Cloudflare. It is never in the web page.
  • If you see "AI is resting for today", the daily question limit was reached. It resets by itself the next day.
  • Free Cloudflare accounts keep question counts only until the helper restarts. For exact daily counts, add a free KV storage named LIMITS to the worker (Settings, Bindings, Add, KV namespace). This is optional.
  • The AI only sets up the test. The Moon Desk does all the math on your real prices.
