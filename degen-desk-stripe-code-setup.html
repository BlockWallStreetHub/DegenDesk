Degen Desk: Unique Code After Stripe Payment

Setup steps for Block Wall Street LLC. About 20 minutes. Follow them in order.

How it works

Customer pays on the Stripe link → Stripe sends them to codebwsddp.html → that page shows their own code (like DD-7K4P-Q2MX) and you get a Web3Forms email saying who paid and which code they got → they enter it with their email on the Desk front page → they get 30 days from the day they first enter it. Each new payment makes a new code. The code only works with the email they paid with.

Step 1: Make a Stripe key that can only read payments

1. In Stripe go to Developers → API keys → Create restricted key.
2. Name it dd-pay. Set Checkout Sessions to Read. Leave everything else as None.
3. Click Create and copy the key (starts with rk_live_). Keep it private: don't paste it into any web page.

Step 2: Create the Cloudflare Worker

1. Cloudflare dashboard → Workers & Pages → Create → Create Worker. Name it exactly dd-pay and click Deploy.
2. Click Edit code, delete everything, paste all of dd-pay-worker.js, then click Deploy.
3. Go to Storage & Databases → KV → Create namespace and name it DD_CODES.
4. Back in the dd-pay Worker: Settings → Bindings → Add → KV namespace. Variable name DD_CODES, pick the namespace you just made.
5. Settings → Variables and Secrets → Add: type Secret, name STRIPE_SECRET_KEY, value = the rk_live key from Step 1. Deploy.
6. Open https://dd-pay.blockwallstreet638.workers.dev/ in your browser. If it says "ok":true, the Worker is running.

If Cloudflare gives the Worker a different web address, tell Claude so the code page can be updated to match.

Step 3: Upload the code page

Upload codebwsddp.html to the DegenDesk GitHub repo, in the same folder as deskbwsddp.html. GitHub: Add file → Upload files → Commit.

Step 4: Point the Stripe Payment Link at the code page

1. Stripe → Payment Links → open the Degen Desk link → Edit → After payment tab.
2. Choose Don't show confirmation page and set the redirect to: 
https://degendesk.blockwallstreet.biz/codebwsddp.html?session_id={CHECKOUT_SESSION_ID}
Type {CHECKOUT_SESSION_ID} exactly like that. Stripe fills in the real payment number for each buyer.
3. Save the link.

Step 5: Two small edits to the Desk front page

Open the front page file in the DegenDesk repo on GitHub, click the pencil icon to edit it, and use Ctrl+F to find each spot.

Edit A. Find this line:

Click at the end of that line, press Enter, and paste this new line under it:

  "stripe-member": {until:"2099-12-31", paid:true},   // codes bought on Stripe (checked by the dd-pay Worker). Do not remove.

Step 6: Test it

Easiest test: in Stripe make a 100% off promo code just for yourself (or a $1 test price), buy through the link, and check that:
✔ you land on the code page and see a DD- code
✔ "Open the Degen Desk" takes you into the desk, with Scalp Scanner and Call-Outs open (paid tier)
✔ you get the Web3Forms "Degen Desk PAID member" email
✔ entering the code with a different email is refused

The code page only gives a code for payments that are actually paid. A $0 checkout with a 100% coupon also counts as paid in Stripe, so delete your test coupon afterwards.

Optional: email the code to the buyer too

This is a backup in case someone closes the page before saving their code.
1. Make a free account at resend.com, add blockwallstreet.biz as a domain, and add the DNS records it gives you in Wix. Then create an API key.
2. In the dd-pay Worker, add Secret RESEND_API_KEY and Text MAIL_FROM = Degen Desk <desk@blockwallstreet.biz>.
3. Stripe → Developers → Webhooks → Add endpoint: URL https://dd-pay.blockwallstreet638.workers.dev/webhook, event checkout.session.completed. Copy its signing secret (whsec_...) into Worker Secret STRIPE_WEBHOOK_SECRET.
Now every buyer gets an email with their code, even if they never see the code page.

Optional: only accept the Degen Desk link

If you use the same Stripe account for other classes, add Worker Text variable PAYMENT_LINK_ID with the Degen Desk link's ID (starts with plink_, shown in the Payment Link's details). Then payments for other products can't be used to get a Desk code.

Looking up who has which code

Cloudflare → KV → DD_CODES → View. Each c:DD-... entry shows the buyer's email, name, amount and when they first used it. Delete an entry to cancel that code.
