How to set each one up (free)
Telegram: message @BotFather, send /newbot, paste the token it gives you. Message your new bot once, open api.telegram.org/bot<token>/getUpdates in a browser and copy the number after "chat":{"id":.
Email: go to web3forms.com, enter the email that should receive alerts, and paste the access key they send you. Each person uses their own key, so alerts go to their own inbox.
Phone: install the free ntfy app, subscribe to a long random topic name, and type the same name above. Alerts arrive as push notifications. WhatsApp: follow CallMeBot's one-time setup to get a key for your number.
Text messages (SMS): normal SMS needs a paid service, so it isn't built in. Phone push, WhatsApp and Telegram all reach your phone for free.
Important: alerts are checked every minute while this page is open in a browser tab. If the tab is closed, nothing is checked. Keys are stored only in this browser.
